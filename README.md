# Busan Red Tide Live

부산 주요 연안의 적조 발생·확산 위험을 공공 해양환경 데이터와 함께 살펴보는 연구·교육용 정적 웹 프로토타입입니다.

현재 적조정보를 단순히 조회하는 화면이 아니라 다음 내용을 한 화면에서 구분해 보여 주는 것을 목표로 합니다.

- 공공기관 실제 관측값
- 관측값과 환경변수로 계산한 자체 0~100 위험지수
- 향후 검증된 예측모델이 제공할 미래 예측값

## 중요 안내

기본 설정에서는 공공 API 키가 비어 있으므로 모든 해양 수치가 `시연모드 · 예시 데이터`로 표시됩니다.

- 예시 데이터는 실제 관측자료가 아닙니다.
- 자체 위험지수는 공식 적조특보와 별개의 연구·교육용 지표입니다.
- 미래 예측모델은 아직 연결하지 않았으며 임의 미래 값을 표시하지 않습니다.
- 실제 대응과 어업·양식장 운영 판단 전에는 국립수산과학원 공식 발표를 확인해야 합니다.

- HTML
- CSS

- Lucide 아이콘 CDN

유료 API, 유료 패키지, 결제가 필요한 서비스는 사용하지 않습니다.

## 실행 방법

별도의 패키지 설치나 빌드 과정이 없습니다.

### Python이 있는 경우

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

### 다른 방법

VS Code의 Live Server와 같은 정적 파일 서버를 사용할 수 있습니다. ES Modules와 공공 API 호출을 사용하므로 `index.html`을 파일로 직접 여는 방식보다 로컬 HTTP 서버를 권장합니다.

## 무료 API 설정

`scripts/config.js`에서 필요한 값만 입력합니다.

```js
window.APP_CONFIG = Object.freeze({
  NIFS_API_KEY: '',
  DATA_GO_KR_KEY: '',
  KHOA_TIDE_OBSERVATION_CODE: '',
  KHOA_BUOY_OBSERVATION_CODE: '',
  KHOA_TIDE_AREA_ID: '',
  KHOA_BUOY_AREA_ID: '',
});
```

KHOA 관측자료를 특정 해역에 적용하려면 다음 해역 ID 중 하나를 설정합니다.

- `gijang`
- `haeundae`
- `gwangalli`
- `yeongdo`
- `dadaepo`
- `gadeokdo`

예:

```js
KHOA_TIDE_OBSERVATION_CODE: '관측소 코드',
KHOA_TIDE_AREA_ID: 'yeongdo',
```

### API 키 보안

이 프로젝트는 정적 프론트엔드 프로토타입이므로 `config.js`에 입력한 키가 브라우저에 노출됩니다.

- 시연·연구 환경에서만 브라우저 직접 호출을 사용하세요.
- 운영 환경에서는 서버 또는 무료 서버리스 프록시에서 키를 관리하세요.
- 도메인·호출량 제한을 지원하는 경우 반드시 제한을 설정하세요.

## 데이터 출처

### 국립수산과학원 NIFS

- 적조정보: `https://www.nifs.go.kr/OpenAPI_json?id=redtideList`
- 실시간 해양수산환경: `https://www.nifs.go.kr/OpenAPI_json?id=risaList`
- 활용 항목: 조사일시, 원인생물, 조사해역, 생물밀도, 수온

### 국립해양조사원 KHOA

- 조위관측소 최신자료: `https://apis.data.go.kr/1192136/dtRecent/GetDTRecentApiService`
- 해양관측부이 최신자료: `https://apis.data.go.kr/1192136/twRecent/GetTWRecentApiService`
- 활용 예정 항목: 수온, 염분, 풍향, 풍속, 유향, 유속, 조위, 기압

### 해양환경공단 KOEM

- 해양환경측정망: `https://apis.data.go.kr/B553931/service/OceansNemoService2/getOceansNemo2`
- 활용 항목: Chl-a, pH, DO, 수온, 염분

### 지도

- 제공된 부산 행정구역 PNG 이미지를 로컬에서 불러옵니다.
- 6개 연안 마커는 이미지 위에 반응형 퍼센트 좌표로 표시됩니다.
- 외부 지도 타일을 내려받지 않아 초기 표시가 빠릅니다.
- 마커 위치는 각 해역의 대략적인 연안 위치를 나타냅니다.

## 데이터 처리 원칙

1. API 키가 없으면 네트워크 요청을 보내지 않습니다.
2. API 호출은 병렬로 실행하며 요청당 8초 제한을 적용합니다.
3. 부산 해역명이 매칭되는 필드만 공식 관측값으로 반영합니다.
4. 매칭되지 않은 필드는 예시값을 유지합니다.
5. 각 상세 지표에 `관측` 또는 `예시` 배지를 표시합니다.
6. CORS, HTTP, 네트워크, 응답 구조 오류가 발생하면 시연모드로 안전하게 전환합니다.
7. NIFS 적조정보에서 확인된 날짜만 공식 관측 달력에 표시합니다.

## 공식 관측과 자체 위험지수의 차이

### 공식 적조특보

공공기관이 조사자료와 현장 상황을 종합해 공식적으로 발표하는 정보입니다.

코클로디니움 세포밀도 비교 기준:

- 10 cells/mL 이상: 예비특보 수준
- 100 cells/mL 이상: 주의보 수준
- 1,000 cells/mL 이상: 경보 수준

화면의 기준 비교 문구는 단순 비교이며 실제 특보 발령을 의미하지 않습니다.

### 자체 위험지수

다음 교육용 가중치로 계산한 0~100 파생지수입니다.

- 세포밀도: 45%
- 수온 적합성: 15%
- Chl-a: 12%
- 염분: 8%
- 용존산소: 5%
- 최근 세포밀도 증가 추세: 15%

수온은 코클로디니움 성장 적합 구간인 24~27℃에서 높은 적합도를 갖도록 설계했습니다.

자체 단계:

- 0~19: 안전
- 20~39: 관심
- 40~59: 주의
- 60~79: 경계
- 80~100: 심각

## 향후 실제 예측모델 개발 방향

1. 시간별 관측자료를 서버에서 수집·정규화합니다.
2. 결측치·이상치와 관측소별 단위 차이를 처리합니다.
3. 수온, 염분, Chl-a, DO, 풍향·풍속, 유향·유속, 조위 자료를 시공간 기준으로 결합합니다.
4. 코클로디니움 세포밀도 예측모델을 학습하고 독립 기간 자료로 검증합니다.
5. 해류·바람 기반 확산모델을 결합해 주변 해역 전파 가능성을 계산합니다.
6. 예측값에 예측 시각, 기간, 불확실성 범위, 모델 버전을 함께 표시합니다.
7. 공식기관 자료와 모델 결과를 지속적으로 비교해 성능을 모니터링합니다.
