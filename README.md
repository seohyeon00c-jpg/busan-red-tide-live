# Busan Red Tide Live

부산 주요 연안의 적조와 해양환경 공식 관측자료를 한 화면에서 살펴보는 연구·교육용 정적 웹 프로토타입입니다.

현재 공개 화면은 다음 원칙을 따릅니다.

- 공공기관 API에서 부산 해역에 매칭된 실제 관측값만 표시
- 공식 응답이 없는 항목은 `자료 없음`으로 표시
- 예시값과 임의 보간값은 사용하지 않음
- 날짜별 해수면수온·해류·파고 수치예보와 관측자료를 조합한 주간 모델 예측 제공

## 중요 안내

공개 사이트는 API 키를 직접 사용하지 않습니다. GitHub Actions가 Secrets의 키로
공공데이터를 수집하고 인증정보가 제거된 캐시를 만들며, 화면은 이 캐시만 읽습니다.
캐시가 없거나 24시간 이상 갱신되지 않으면 숫자를 대체하지 않고 `공식자료 없음`
상태로 전환됩니다.

- 현재 공식 세포밀도가 없어 종합 적조 위험지수는 산정하지 않습니다.
- 주간 전망은 무료 해양 수치예보의 날짜별 수온·해류·파고를 사용합니다.
- 공식 세포밀도가 없으면 해당 가중치를 0점으로 유지해 환경조건만으로 높은 단계가 나오지 않게 합니다.
- 주간 전망은 연구·교육용 모델 결과이며 공식 적조 예보가 아닙니다.
- 공식 세포밀도가 없으면 공식 기준 비교도 수행하지 않습니다.
- 실제 대응과 어업·양식장 운영 판단 전에는 국립수산과학원 공식 발표를 확인해야 합니다.

## 사용 기술

- HTML
- CSS
- JavaScript ES Modules
- Tailwind CSS CDN
- 제공된 부산 행정구역 이미지
- Lucide 아이콘 CDN

유료 API, 유료 패키지, 결제가 필요한 서비스는 사용하지 않습니다.

## 실행 방법

별도의 패키지 설치나 빌드 과정이 없습니다.

### Python이 있는 경우

프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

### 다른 방법

VS Code의 Live Server와 같은 정적 파일 서버를 사용할 수 있습니다. ES Modules와 공공 API 호출을 사용하므로 `index.html`을 파일로 직접 여는 방식보다 로컬 HTTP 서버를 권장합니다.

## 무료 API와 GitHub Secrets 설정

API 키는 `config.js`나 브라우저 코드에 입력하지 않습니다. 저장소의 GitHub
Secrets에 다음 이름으로 등록합니다.

```text
NIFS_API_KEY
DATA_GO_KR_KEY
```

`.github/workflows/collect-public-data.yml`이 3시간마다 다음 작업을 수행합니다.

1. GitHub Secrets를 이용해 NIFS·KOEM·부산시 해양환경측정망 API를 호출합니다.
2. 인증키가 포함되지 않은 `data/live-marine.json`만 생성합니다.
3. GitHub Pages 소스 브랜치에 공개 캐시를 커밋합니다.
4. GitHub Pages 재배포를 요청합니다.

브라우저는 `scripts/config.js`에 지정된 공개 JSON만 읽습니다.

```js
window.APP_CONFIG = Object.freeze({
  PUBLIC_DATA_CACHE_URL: './data/live-marine.json',
});
```

워크플로는 기본 브랜치에 병합된 뒤 예약 실행됩니다. GitHub Actions 화면의
`Collect public marine data`에서 `Run workflow`를 눌러 즉시 수동 수집할 수도
있습니다.

### API 키 보안

- GitHub Secrets의 값은 웹사이트와 공개 JSON에 포함되지 않습니다.
- 수집 스크립트는 출력 파일에서 키 문자열이 감지되면 저장을 중단합니다.
- 공개 캐시가 없거나 24시간 이상 갱신되지 않으면 모든 수치를 `자료 없음`으로 표시합니다.
- Actions 로그에 인증키나 키가 포함된 요청 URL을 출력하지 않습니다.

## 데이터 출처

### 국립수산과학원 NIFS

- 적조정보: `https://www.nifs.go.kr/OpenAPI_json?id=redtideList`
- 실시간 해양수산환경: `https://www.nifs.go.kr/OpenAPI_json?id=risaList`
- 활용 항목: 조사일시, 원인생물, 조사해역, 생물밀도, 수온

### 국립해양조사원 KHOA

- 기존 조위관측소·해양관측부이 최신자료 API는 2026년 1월 제공이 중단됐습니다.
- 국가중점데이터로 새로 개방된 대체서비스의 규격을 확인한 뒤 연결할 예정입니다.
- 대체서비스 연결 전에는 KHOA 값을 실제 관측값으로 표시하지 않습니다.

### 해양환경공단 KOEM

- 해양환경측정망: `https://apis.data.go.kr/B553931/service/OceansNemoService2/getOceansNemo2`
- 활용 항목: Chl-a, pH, DO, 수온, 염분

### 부산광역시 보건환경연구원

- 부산 해양환경 측정망 API: `https://apis.data.go.kr/6260000/BusanMrnEnvrnInfoService/getMrnEnvrnInfo`
- 활용 항목: 해운대·광안리 정점의 Chl-a, pH, DO, 수온, 염분
- 최신 분기 API 응답을 우선 사용합니다.
- API가 승인되지 않았거나 응답에 해당 정점이 없으면 부산시 「2024년 해양환경측정망」 보고서의 연평균 공식값을 사용하고 화면에 `2024년 연평균`이라고 표시합니다.
- 부산시 자료에는 적조 생물 세포밀도와 자체 위험지수가 없으므로 해당 항목은 임의 계산하지 않고 `자료 없음`으로 유지합니다.

### Open-Meteo Marine API

- 문서: `https://open-meteo.com/en/docs/marine-weather-api`
- 활용 항목: 날짜별 해수면수온, 해류속도, 파고
- 부산 6개 해역 좌표별 시간자료를 일평균으로 집계해 8일 전망에 사용합니다.
- API 키가 필요 없는 무료 수치예보이며 Open-Meteo와 원 수치모델 제공기관을 화면에 표시합니다.
- 연안 격자 예보는 공간 해상도에 한계가 있으므로 항해·안전 판단에 사용하지 않습니다.

### 지도

- 제공된 부산 행정구역 PNG 이미지를 로컬에서 불러옵니다.
- 6개 연안 마커는 이미지 위에 반응형 퍼센트 좌표로 표시됩니다.
- 외부 지도 타일을 내려받지 않아 초기 표시가 빠릅니다.
- 마커 위치는 각 해역의 대략적인 연안 위치를 나타냅니다.

## 데이터 처리 원칙

1. API 키는 GitHub Actions에서만 사용합니다.
2. API 호출은 병렬로 실행하며 요청당 8초 제한을 적용합니다.
3. 부산 해역명이 매칭되는 필드만 공식 관측값으로 반영합니다.
4. 매칭되지 않은 필드는 `null`로 유지하고 화면에 `자료 없음`으로 표시합니다.
5. 각 상세 지표에 `관측` 또는 `자료 없음` 배지를 표시합니다.
6. CORS, HTTP, 네트워크, 응답 구조 오류가 발생해도 임의 숫자를 생성하지 않습니다.
7. NIFS 적조정보에서 확인된 날짜만 공식 관측 달력에 표시합니다.
8. 브라우저는 24시간 이내에 생성된 공개 캐시만 사용합니다.

## 공식 관측과 모델 예측

### 공식 적조특보

공공기관이 조사자료와 현장 상황을 종합해 공식적으로 발표하는 정보입니다.

코클로디니움 세포밀도 비교 기준:

- 10 cells/mL 이상: 예비특보 수준
- 100 cells/mL 이상: 주의보 수준
- 1,000 cells/mL 이상: 경보 수준

화면의 기준 비교 문구는 단순 비교이며 실제 특보 발령을 의미하지 않습니다.

### 자체 위험지수와 예측

세포밀도, 수온, Chl-a, 염분, 용존산소, 최근 증가 추세가 모두 공식자료로
확보되기 전까지 종합 자체 위험지수는 산정하지 않습니다.

주간 전망은 날짜별 해수면수온·해류·파고 수치예보와 현재 공식
Chl-a·염분·용존산소·세포밀도를 가중 결합한 0~100 모델 지수입니다.
모든 모델 위험도는 세포밀도 45%, 증가추세 15%, 예측수온 15%,
Chl-a 10%, 염분 5%, 용존산소 3%, 해류 정체 4%, 잔잔한 파고 3%의
단일 계산식을 사용합니다. 지도 마커, 상세 카드의 오늘 점수와 첫 번째 막대는
같은 결과를 공유합니다. 관측 세포밀도나 증가추세가 없으면 해당 가중치를 다른 환경요소에
재분배하지 않고 0점으로 유지합니다. 따라서 이 값은 적조 발생확률이 아니며
공식 적조특보와 별개입니다. 해양 수치예보 연결에 실패하면 같은 값을 복사하거나
임의 숫자로 대체하지 않고 `예측자료 없음`으로 표시합니다.

- 부산 행정구역 이미지 기반 간편 지도

- 선택 해역 상세 지표와 필드별 출처
- 공식 세포밀도가 있을 때만 공식 기준 비교

- 날짜별 해수면수온·해류·파고를 반영한 선택 해역 주간 예측
- 현재 연·월 자동 월간 달력
- 공식 적조 관측일만 표시하는 달력
- 공공 API 연결 상태와 자료 없음 처리
- 데스크톱·태블릿·스마트폰 반응형 UI

## 향후 실제 예측모델 개발 방향

현재 공개 화면의 주간 전망은 해양 수치예보와 관측자료를 결합한 규칙 기반 모델 지수입니다.
아래 단계로 실제 시계열 예측모델을 개발하고 검증해 정확도와 활용도를
높일 예정입니다.

모델 설계 시 코클로디니움의 환경 영향인자를 설명하는
[국립수산과학원 적조 안내서](https://www.nifs.go.kr/red/manual/redtide.pdf)와
[코클로디니움 최적 성장모형 연구](https://doi.org/10.9765/KSCOE.2014.26.4.217)를
참고했습니다. 현재 구현은 해당 연구를 그대로 재현한 모델이 아닙니다.

1. 시간별 관측자료를 서버에서 수집·정규화합니다.
2. 결측치·이상치와 관측소별 단위 차이를 처리합니다.
3. 수온, 염분, Chl-a, DO, 풍향·풍속, 유향·유속, 조위 자료를 시공간 기준으로 결합합니다.
4. 코클로디니움 세포밀도 예측모델을 학습하고 독립 기간 자료로 검증합니다.
5. 해류·바람 기반 확산모델을 결합해 주변 해역 전파 가능성을 계산합니다.
6. 예측값에 예측 시각, 기간, 불확실성 범위, 모델 버전을 함께 표시합니다.
7. 공식기관 자료와 모델 결과를 지속적으로 비교해 성능을 모니터링합니다.
